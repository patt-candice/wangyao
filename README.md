# วังยาว • ทะเบียนสิ่งของ ซ่อม ยืมคืน

ระบบบริหารครุภัณฑ์ แจ้งซ่อม ยืมคืน และจำหน่าย สำหรับวังยาวรีสอร์ท (ผู้ใช้ไม่เกิน 20 คน)

- **ฐานข้อมูล:** Google Sheet (สร้างอัตโนมัติด้วย `setupDatabase`)
- **Backend:** Google Apps Script (`apps-script/Code.gs`)
- **หน้าเว็บ:** `public/index.html` ไฟล์เดียว โฮสต์บน Vercel
- **Gateway:** `api/gas.js` (Vercel serverless) ลงลายเซ็นทุกคำขอ และคำนวณรหัสผ่าน PBKDF2 แทน GAS

```
เบราว์เซอร์ ──POST /api──▶ Vercel (api/gas.js) ──HMAC──▶ Apps Script (Code.gs) ──▶ Google Sheet / Drive
                                                             └─ CacheService (snapshot ข้อมูลทั้งระบบ)
```

## โครงสร้างไฟล์

```
wangyao/
├─ apps-script/
│  ├─ Code.gs            # backend ทั้งหมด
│  └─ appsscript.json    # สิทธิ์ (oauthScopes), timeZone Asia/Bangkok, web app
├─ public/index.html     # หน้าเว็บไฟล์เดียว
├─ api/gas.js            # Vercel gateway (Node 20+)
├─ vercel.json           # maxDuration 60, header, rewrite /api
├─ package.json
├─ test/                 # ชุดทดสอบ (ไม่ต้องอัปโหลดขึ้น Apps Script)
└─ README.md
```

## ขั้นตอนติดตั้ง (ทำตามทีละข้อ)

> ใช้บัญชี Google ของเจ้าของกิจการตลอดทุกขั้นตอน (บัญชีนี้จะเป็นผู้ดูแลระบบคนแรก)

### 1. สร้างโปรเจกต์ Apps Script ที่ผูกกับ Google Sheet

1. เปิด <https://sheets.new> เพื่อสร้าง Google Sheet ใหม่ ตั้งชื่อว่า `วังยาว • ฐานข้อมูล`
2. เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. ตั้งชื่อโปรเจกต์ (มุมซ้ายบน) เช่น `วังยาว`

> ต้องสร้างจากใน Google Sheet แบบนี้ เมนู "วังยาว" ในชีตจึงจะแสดง

### 2. วางไฟล์ `appsscript.json`

1. ใน Apps Script กดไอคอน ⚙️ **Project Settings** → ติ๊ก **Show "appsscript.json" manifest file in editor**
2. กลับไปหน้า **Editor** (ไอคอน `< >`) เปิดไฟล์ `appsscript.json`
3. ลบของเดิมทั้งหมด แล้ววางเนื้อหาจาก `apps-script/appsscript.json` → กด 💾 บันทึก

### 3. วางไฟล์ `Code.gs`

1. เปิดไฟล์ `Code.gs` ใน Editor ลบของเดิมทั้งหมด
2. วางเนื้อหาจาก `apps-script/Code.gs` ทั้งไฟล์ → กด 💾 บันทึก

### 4. รัน `setupDatabase` (สร้างฐานข้อมูล) และอนุญาตสิทธิ์

1. ที่แถบด้านบน เลือกฟังก์ชัน **setupDatabase** → กด **▶ Run**
2. จะมีหน้าต่างขออนุญาต → **Review permissions** → เลือกบัญชีของคุณ
3. ถ้าขึ้น "Google hasn't verified this app" ให้กด **Advanced → Go to วังยาว (unsafe)** → **Allow**
   (เป็นสคริปต์ของคุณเอง ไม่ได้ส่งข้อมูลออกนอกบัญชี)
4. รอจนเสร็จ (ประมาณ 20–60 วินาที) ดูผลที่ **Execution log**

ระบบจะสร้าง: แท็บทั้ง 24 แท็บพร้อมหัวคอลัมน์, บทบาท 7 แบบ, ตัวเลือก (หมวด/หน่วย/ยี่ห้อ/เหตุผลจำหน่าย/แผนก), สถานที่ (สต๊อกกลาง + ห้องต่าง ๆ),
ค่าตั้งต้นระบบ, ผู้ดูแลจากอีเมลของคุณ, โฟลเดอร์ Drive (ภาพ / เอกสาร PDF) และ trigger (ทุก 1 นาที, รายวัน 03:00, เมื่อแก้ชีต)

> รันซ้ำได้ทุกเมื่อ ระบบจะเติมเฉพาะส่วนที่ขาด **ไม่ลบข้อมูลเดิม**

### 5. ตั้งรหัสผ่านเจ้าของ

1. กลับไปที่ Google Sheet แล้วกด **รีเฟรชหน้า (F5)** จะมีเมนู **วังยาว** ขึ้นที่แถบเมนู
2. เมนู **วังยาว → 2) ตั้งรหัสผ่านเจ้าของ**
3. ใส่รหัสผ่าน (อย่างน้อย 8 ตัว มีทั้งตัวเลขและตัวอักษร) สองครั้ง
4. รอประมาณ 30–60 วินาที (คำนวณ PBKDF2 600,000 รอบใน GAS ครั้งเดียว) จนขึ้น "ตั้งรหัสผ่านเรียบร้อย"

### 6. Deploy เป็น Web app

1. ใน Apps Script กด **Deploy → New deployment**
2. กด ⚙️ ข้าง "Select type" → เลือก **Web app**
3. ตั้งค่า:
   - Description: `v1`
   - **Execute as: Me** (อีเมลของคุณ)
   - **Who has access: Anyone**
4. กด **Deploy** → คัดลอก **Web app URL** (ลงท้ายด้วย `/exec`) เก็บไว้

### 7. Deploy หน้าเว็บขึ้น Vercel

วิธีที่ง่ายที่สุด (ผ่าน GitHub):

1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดทั้งโฟลเดอร์ `wangyao/`
2. เข้า <https://vercel.com/new> → **Import** repository นั้น
3. Framework Preset: **Other** (ไม่ต้องตั้ง Build Command) → กด **Deploy**
4. เมื่อเสร็จ จะได้ที่อยู่เว็บ เช่น `https://wangyao.vercel.app` คัดลอกเก็บไว้

> หรือใช้ Vercel CLI: ติดตั้ง Node.js แล้วรัน `npx vercel deploy --prod` ในโฟลเดอร์ `wangyao/`

### 8. เชื่อมต่อ Vercel กับ Apps Script

1. ใน Google Sheet เมนู **วังยาว → 3) เชื่อมต่อ Vercel**
2. ใส่ที่อยู่เว็บจากข้อ 7 (เช่น `https://wangyao.vercel.app`) → OK
3. จะมีหน้าต่างแสดงค่า **GAS_URL** และ **GAS_BRIDGE_SECRET** ให้คัดลอก
   (ถ้า GAS_URL ไม่แสดง ให้ใช้ URL จากข้อ 6 — ต้องลงท้าย `/exec`)

### 9. ตั้งค่า Environment Variables บน Vercel

1. Vercel → เลือกโปรเจกต์ → **Settings → Environment Variables**
2. เพิ่ม 2 ค่า โดยติ๊กทั้ง **Production** และ **Preview**

   | Key | Value |
   |---|---|
   | `GAS_URL` | Web app URL จากข้อ 6 (ลงท้าย `/exec`) |
   | `GAS_BRIDGE_SECRET` | ค่าจากข้อ 8 (ยาว 64 ตัวอักษร) |

3. ไปที่แท็บ **Deployments** → กด ⋯ ที่รายการล่าสุด → **Redeploy** (จำเป็น ไม่เช่นนั้นค่าใหม่จะยังไม่มีผล)

### 10. ทดสอบล็อกอิน

1. เปิดที่อยู่เว็บบน Vercel
2. ใส่อีเมลเจ้าของ และรหัสผ่านจากข้อ 5 → **เข้าสู่ระบบ**
3. ใน Google Sheet เมนู **วังยาว → ตรวจระบบ (health check)** ควรเป็น ✅ ทั้งหมด

## ตั้งค่าแจ้งเตือนเจ้าของ (ไม่บังคับ)

เมนูเว็บ **จัดการระบบ → แจ้งเตือน**

- **Telegram:** สร้างบอทกับ @BotFather ได้ Bot Token, ส่งข้อความหาบอทหนึ่งครั้ง แล้วหา Chat ID (เช่นผ่าน @userinfobot)
- **LINE Messaging API:** สร้าง Messaging API channel ที่ LINE Developers → Channel access token (long-lived) และ User ID ของคุณ (หน้า Basic settings)

ระบบส่งเมื่อ: แจ้งซ่อมใหม่, งานรออนุมัติ, ขอแก้ไขวงเงิน, งานรอตรวจรับ, เสนอจำหน่าย, ผู้สมัครใหม่, สรุปการยืมใกล้/เกินกำหนดทุกเช้า (หลัง 08:00)
token เก็บใน Script Properties เท่านั้น ไม่ถูกส่งมาที่เบราว์เซอร์

## เข้าสู่ระบบด้วย Google (ไม่บังคับ)

1. Google Cloud Console → APIs & Services → Credentials → **Create OAuth client ID** → Web application
2. Authorized JavaScript origins: ใส่ที่อยู่เว็บ Vercel
3. คัดลอก Client ID ไปใส่ที่เว็บ **จัดการระบบ → ตั้งค่าระบบ** แล้วติ๊ก "เปิดเข้าสู่ระบบด้วย Google"
4. ผู้ใช้ต้องมีบัญชีในระบบที่อีเมลตรงกันก่อน (ครั้งแรกระบบจะผูกบัญชี Google ให้อัตโนมัติ)

## การทำงานด้านความเร็ว (สรุป)

- ข้อมูลทั้งระบบเก็บเป็น **snapshot** ใน CacheService (gzip+base64 แยก chunk ต่อตาราง ≤ 90,000 อักขระ, TTL 6 ชม.) การอ่านทุกชนิด **ไม่เปิด Spreadsheet**
- `STATE_REV` (Script Properties) เป็นเลขเวอร์ชัน อ่านซ้ำหลังโหลดเพื่อกัน torn read; แก้ชีตด้วยมือ → trigger เปลี่ยน rev → สร้างใหม่อัตโนมัติ
- การบันทึก: เขียนชีตก่อน (ตรวจ `getLastRow()` + id ของแถวที่จะแก้ ถ้าไม่ตรง = drift → สร้าง snapshot ใหม่แล้วลองอีกครั้ง ไม่เขียนผิดแถว) → แพตช์เฉพาะตารางที่เปลี่ยน → `flush()` ครั้งเดียว
- Write-ahead journal: แถว `Operations` (PREPARED → COMMITTED) + `PEND` ใช้กู้คืนเมื่อ GAS หยุดกลางคัน
- **ล็อกอิน = คำขอเดียว** คืน `{token, user, state}` และไม่เปิด Spreadsheet (บันทึกแถว Sessions/AuditLogs ผ่านคิว ภายใน 1 นาที)
- บันทึกทุกชนิดคืน `{data, state}` โดยส่งเฉพาะ **แถวที่เปลี่ยน** หน้าเว็บวาดใหม่ทันทีไม่ต้องเรียกซ้ำ
- เปลี่ยนเมนู/หน้า ไม่เรียกเซิร์ฟเวอร์; รีเฟรชอัตโนมัติทุก 2 นาที (เฉพาะตอนแท็บเปิดอยู่และไม่มีฟอร์มเปิด) ถ้าข้อมูลไม่เปลี่ยนตอบกลับทันทีโดยไม่โหลด snapshot

**ข้อควรทราบ (ตรงไปตรงมา):** ตัวเลขด้านบนวัดในเครื่องกับตัวจำลอง ยัง **ไม่ได้วัดบน Vercel + Apps Script จริง** เพราะต้องใช้บัญชี Google/Vercel ของคุณ
เวลาจริงขึ้นกับความเร็วของ Google ซึ่งโดยทั่วไป: การเปิดชีต 0.5–1.5 วินาที, การเรียกชีตครั้งละ 0.05–0.3 วินาที, overhead ของ Apps Script 0.3–1 วินาทีต่อคำขอ
ประมาณการ: ล็อกอิน 2–3.5 วินาที (2 คำขอไป GAS + PBKDF2 ที่ Vercel ~0.4 วินาที), บันทึก 2–3.5 วินาที, รีเฟรช 0.5–1.5 วินาที
วิธีวัดหลังติดตั้ง: ดู "ตอบสนอง x.x วินาที" ที่แถบสถานะ และ Apps Script → **Executions** (ดูเวลาแต่ละคำขอ) ถ้าเกินเกณฑ์ ให้ตรวจว่าเปิด Sheets API แล้ว และ trigger `cronMinute` ทำงานอยู่

## โควตาของ Google ที่ควรรู้

- trigger ทุก 1 นาที = 1,440 ครั้ง/วัน ปกติแต่ละครั้งใช้เวลาไม่ถึง 1 วินาที (ไม่มีงานจะจบเร็วโดยไม่ถอด snapshot)
  บัญชี Gmail ทั่วไปมีโควตารวม trigger 90 นาที/วัน, Google Workspace 6 ชม./วัน — ถ้าเกินโควตา ระบบยังใช้ได้ แค่ไม่มีการอุ่นแคช/ส่งแจ้งเตือนจนถึงวันถัดไป
- ส่งอีเมล (ลืมรหัสผ่าน): Gmail 100 ฉบับ/วัน

## ความปลอดภัย (สรุป)

- รหัสผ่าน PBKDF2-SHA256 600,000 รอบ + salt ต่อผู้ใช้ เปรียบเทียบแบบ constant-time; ไม่ส่ง hash/salt/token ไปเบราว์เซอร์
- token เซสชันสุ่ม 96 ตัวอักษร เก็บเฉพาะ HMAC ในชีต, เบราว์เซอร์เก็บใน `sessionStorage`, อายุ 10 ชม.
- จำกัดการลองล็อกอิน 8 ครั้ง/15 นาที/บัญชี; ลิงก์ลืมรหัสใช้ครั้งเดียว อายุ 15 นาที; ไม่บอกว่ามีบัญชีหรือไม่
- Gateway: ตรวจ Origin, allow-list เมธอด, HMAC + timestamp 90 วินาที + nonce กันส่งซ้ำ, จำกัดขนาด (JSON 1.5 MB, ไฟล์ 5 MB)
- ตรวจสิทธิ์ทุก action ที่เซิร์ฟเวอร์; ช่างเห็นเฉพาะงานของตัวเอง; ผู้ไม่มีสิทธิ์การเงินไม่ได้รับราคา/วงเงิน/ค่าซ่อม
- escape ข้อความทุกจุด (กัน XSS), กัน formula injection ทั้งในชีตและ CSV, ไฟล์แนบตรวจ magic bytes
- AuditLogs บันทึกทุกการกระทำ (ไม่เก็บรหัสผ่าน/token) และไม่ถูกลบ
